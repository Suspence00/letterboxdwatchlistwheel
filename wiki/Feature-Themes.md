# Feature: Visual Themes

The **Letterboxd Watchlist Wheel** features a collection of 13 rich, handcrafted visual themes designed to transform the atmosphere of your movie night. Themes tailor every visual element: typography, card backdrops, button gradients, atmospheric particles, ambient animations, and wheel slice palettes.

---

## Accessing & Selecting Themes

Themes can be configured in the **Settings Modal**:

1. Click the **Settings ⚙️** button in the header or navigation bar.
2. Select the **Themes** tab to view the accessible theme preview cards.
3. Browse between **Everyday** and **Seasonal** categories.
4. Click any theme card to preview and apply it immediately. Full keyboard navigation (<kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> <kbd>Home</kbd> <kbd>End</kbd>) is supported.
5. Use the **Enable ambient theme decorations** checkbox (`decorationsEnabled` preference) to toggle theme-specific background animations, particles, and floating elements on or off.

## Slice Color Behavior & Custom Tuning

A key feature of the theme architecture is the intelligent handling of **Slice Colors**:

```
                 ┌───────────────────────────────────────────────────────────┐
                 │                Active Theme Palette Logic                 │
                 └─────────────────────────────┬─────────────────────────────┘
                                               │
                       ┌───────────────────────┴───────────────────────┐
                       ▼                                               ▼
             [ Classic Theme ]                                [ Styled Themes ]
                       │                                               │
      Is there a custom slice color?                     Theme palette locks color!
                       │                                               │
            ┌──────────┴──────────┐                                    ▼
            ▼                     ▼                          Uses theme-tailored
      [Custom Hex]        [Default Base]                           cohesive palette
            │                     │                                    │
            └──────────┬──────────┘                                    │
                       ▼                                               │
       Renders with custom slice tuning                                │
                       ▲                                               │
                       └─────────── [ Return to Classic ] ─────────────┘
```

1. **Custom Slices in Classic Theme**:
   * When using the **Classic** theme, you can freely customize individual slice colors using the **Slice Editor**.
   * Any color assigned to a movie is saved permanently in state (`movie.color`).
2. **Cohesive Palette Locking in Themed Modes**:
   * When switching to any styled theme (such as *Fantasy*, *Modern*, *Alaska*, or *Forest Camp*), the wheel locks to that theme's curated palette (`isThemePaletteLocked() === true`).
   * This guarantees that cards, labels, and wheel slices remain visually harmonious without color clashes.
3. **Safe Restoration**:
   * Switching away from Classic does **not** delete or overwrite your custom slice colors.
   * As soon as you return to the **Classic** theme, all your custom movie slice colors are instantly restored.

## Ambient Decorations & Performance

All ambient theme elements (falling snow, flying bats, glowing campfire flames, floating pot of gold, swaying lanterns, and firework bursts) are engineered with modern performance and accessibility standards:

* **Zero JavaScript Overhead**: Ambient effects are driven purely by hardware-accelerated CSS keyframe animations (`transform` and `opacity`).
* **One-Click Toggle**: If you prefer a distraction-free screen or are running on low-power mobile devices, uncheck **Enable ambient theme decorations** in the theme picker to hide all atmospheric particles instantly.
* **Respects Reduced Motion**: All ambient particle animations automatically disable or freeze when `prefers-reduced-motion: reduce` is detected in the user's operating system settings.
